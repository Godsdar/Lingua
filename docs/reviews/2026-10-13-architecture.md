# Архитектурное ревью Lingua — 13 октября 2026

Исходная база: `cae51f6`. Проверены концепт, общий словарный код, контракты, сборки, документация и CI. Это ревью текущего продукта и изменений данного прохода, а не аудит всей инфраструктуры или точности внешних словарей.

**Вывод:** исходная идея сохранена, но продукт пока является исследовательским демо. Можно проверять UX с первыми добровольцами. Обещать пользователям живой разбор любого предложения и надёжное хранение работ пока нельзя.

## Критичные для качества данных проблемы

### P1 — соседние формы могли стать выдуманной цепочкой предков: исправлено

Где: [chainFromEtyTree](../../src/core/wiktionary.ts), регрессии в [wiktionary.test.ts](../../src/core/wiktionary.test.ts).

Рекурсивный обход складывал все соседние `children`/`terms` в линейный список. Последующий рендер цепочки представлял соседство как историческую последовательность. Теперь линейный fallback отклоняет ветвление и некорректную структуру; доступная цепочка из wikitext сохраняется. Это может уменьшить полноту дерева, зато не создаёт связи из порядка обхода. Полная модель исторического графа для живого словаря остаётся отдельной работой.

### P1 — экспорт после правки смешивал старый анализ и новый текст: исправлено

Где: [контроллер концепта](../../web/concept/concept.js), [область экспорта](../../web/concept/domain/reports.ts).

Редактирование блокировало сохранение, но экспорт мог сформировать заметку с новым текстом и прежними токенами. JSON также добавлял несохранённый текущий документ к старым заметкам. Теперь результат скрывается до нового Explore; экспорт текущего устаревшего выделения недоступен. Сохранённые снимки клонируются, а отчёт включает только связанные с ними документы. Ограничение сессионных заметок стало видимым в UI.

## Важные ограничения перед реальной альфой

### P1 — живое ядро не разбирает предложения: открыто

Где: [analyze.ts](../../src/core/analyze.ts), `uniqueWords(...).slice(0, MAX_WORDS)`; [контракт](../../src/shared/types.ts).

Исчезают повторные вхождения и позиции; словарный POS не учитывает контекст. Концепт лучше сохраняет контекст, но использует три подготовленных примера. Подключать старый `analyze` под кнопку нового синтаксического вида нельзя. Следующий этап: [сравнение движков](../ENGINE_EVALUATION.md), нормализованный контракт вхождений/зависимостей, отдельные статусы слоёв, защита от устаревших async-ответов.

### P1 — заметки не переживают перезагрузку: открыто, явно обозначено

Где: массив `notes` в [concept.js](../../web/concept/concept.js).

Пользователь может потерять работу, если воспримет Save как постоянное хранение. Кнопка теперь называется “Save for this session”, рядом с заметками есть напоминание экспортировать. Для альфы нужен versioned notebook: восстановление, миграции, ошибки квоты, удаление, безопасный импорт и неизменяемые снимки. Не добавлять наспех без проверок потери данных.

### P2 — две поверхности и смешанный контроллер: частично исправлено

Где: [Vite entry](../../web/vite.config.ts), [typed domain](../../web/concept/domain/), [React explorers](../../web/concept/components/explorers.tsx), [concept.js](../../web/concept/concept.js).

Раньше концепт копировался из public и полностью обходил TypeScript. Сейчас он отдельный Vite entry; графы и разрешение выделений типизированы и проверяются. CSS-токены отделены от доменной логики. Остальной JS-контроллер всё ещё смешивает шаблоны, состояние заметок и сериализацию. Постепенно извлечь editor/notebook/report services, затем перенести согласованный workspace в основное приложение. Не переписывать три поверхности одновременно.

### P2 — ошибки словаря и отсутствие данных не различаются: открыто

Где: `safeLexicons` в [analyze.ts](../../src/core/analyze.ts); `catch` возвращает пустую Map.

Сбой сервиса может выглядеть как отсутствие истории слова. При следующем изменении API добавить independent layer status (`ready / unavailable / error`) и retry. Переводческая ошибка не должна скрывать грамматику. Текущий проход не меняет IPC-контракт всех поверхностей.

### P2 — модель исторических связей всё ещё неполна: открыто

Где: [EtyTreeNode](../../src/core/etymologyTree.ts), [EtymologyNode](../../src/shared/types.ts).

Рендер линейных цепей теряет тип связи; два алгоритма определения общего предка используют разные критерии. Для живого семейного графа необходимы явные nodes/edges, inheritance/borrowing/derivation, доказательство каждого ребра, отдельные значения и пометки неполноты. Не выдавать совпадение значения за когнатность. Структурные тестовые слова не являются лингвистическими источниками.

## Соответствие исходной концепции

| Требование | После изменений |
|---|---|
| Английский интерфейс, минимализм, темы | Сохранено; предпочтение темы/вида хранится локально |
| Дизайн отделён от логики | Typed domain + React explorers + CSS tokens; контроллер ещё требует выделения модулей |
| Красивое 2D-дерево с умеренной плотностью | Ветви по языкам, подсветка предков, фокус пути, прокрутка и масштаб |
| Плавные осмысленные анимации | Motion, стабильные ID, 320/180 ms, reduced motion |
| Морфология и синтаксические связи | Инспектор признаков + интерактивные дуги + полная таблица; подготовленные данные |
| Слова, выражения, длинный текст | Точные вхождения и контекст; выражение не получает ложную общую этимологию |
| Отчёт и источники | Markdown / JSON / HTML; исправлена область экспорта |
| Бюджет $0 | Статический Vercel/Pages, backend и платные API не добавлены |

## Проверки и релиз

- Автоматические регрессии: ветвление/цикл/неизвестный родитель, источник рёбер, точные повторные вхождения после emoji, отсутствие выдуманного анализа, dependency heads и область JSON-экспорта.
- Typecheck охватывает новые TypeScript-компоненты и домен. Собираются web, Electron и extension.
- Docker приведён к Node 24; target `ci` теперь запускает также тесты. Vercel build выполняет тесты и typecheck перед web build. Локальный Docker daemon в этом проходе не использовался; контейнер проверяется GitHub CI.
- Браузерная проверка: переключение тем, раскрытие ветви, синтаксический выбор с сохранением фокуса, выделение выражения, сессионная заметка после правки, ограниченная ширина и reduced motion. Автоматического end-to-end browser suite пока нет.
- Vercel по-прежнему публикуется явно через CLI; Pages обновляется от main. Сборочные проверки не являются uptime-мониторингом и не гарантируют доступность провайдеров.
